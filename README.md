# Julius Evola Daily

A 365-day reader for young men, drawn primarily from Julius Evola’s *Revolt Against the Modern World* and *Ride the Tiger*, with support from *Men Among the Ruins* and *Meditations on the Peaks*.

## Structure

- Days 1–15: Orientation
- Days 16–35: Diagnosis of the Modern World
- Days 36–55: The Traditional Order
- Days 56–75: The Differentiated Individual
- Days 76–100: Riding the Tiger
- Days 101–130: Intensification / Application
- Days 131+: Deeper residual / application material

**Currently complete through Day 195.** Remaining days marked “Coming soon” on the index.

## Features

- Dark / light theme (persists)
- Listen (text-to-speech)
- Share quote as image
- Report inaccuracy (opens GitHub issue)
- Clean, readable typography optimized for long-form
